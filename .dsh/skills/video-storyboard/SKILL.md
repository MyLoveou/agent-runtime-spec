# 分镜

## 何时用

- 要生成视频（Wan / 可灵 / Seedance / 即梦…）之前，先定「每个镜头长什么样」；
- 一个剧本片段不知道拆几个镜头、每个镜头用什么景别；
- 多镜头之间角色脸/服装/画风漂移，需要一致性方案。

不适用：已有成片素材的剪辑（用 `video-compose`）、纯口播（用 `video-shortform-script`）。

## 六步

| # | 步骤 | 产出 |
|---|---|---|
| 1 | 拆片段 | 按信息点切成 5s / 10s / 15s 档 |
| 2 | 判内容类型 | 六类互斥：对白 / 动作 / 情绪 / 环境 / 悬念 / 揭示 |
| 3 | 查五张表 | 景别 · 角度 · 运镜 · 光影 · 节奏 |
| 4 | 冲突仲裁 | 情绪 > 信息 > 权力 |
| 5 | 定图数 | 档位 × 节奏交叉表 + 运镜复杂度修正 |
| 6 | 出提示词包 | 定妆照 → 场景图 → 分镜图 → 视频 |

细节见 [references/decision-tables.md](references/decision-tables.md) 与 [references/prompt-templates.md](references/prompt-templates.md)。

## 三条硬规则

1. **先建议后定档**：拆完先给《档位建议表》，用户确认后才定图数、出提示词；
2. **定妆照先行**：任何角色先出一张正脸、无遮挡、均匀打光的定妆照，作为全片锁脸源；
3. **一次只改一个变量**：改动作不改脸，改场景不改角色；否则漂移后无法归因。

## 一致性清单（每镜都要核）

| 项 | 要求 |
|---|---|
| 身份 | 同一张定妆照贯穿全片，不中途换脸 |
| 场景 | 同场景共用一张场景设定图，换机位不换场景 |
| 服装 | 颜色/款式/破损状态逐帧延续 |
| 道具 | 刀、伤痕、关键物件的位置与状态连续 |
| 位置 | 场景内相对位置与轴线不跳 |

## 负面清单（分两层用）

- **A 层进负面词**：`deformed, bad anatomy, extra fingers, text, watermark, oversaturated, overexposed`；
- **B 层进决策**：不要用「超过 8 秒且无信息量」的长镜头；不要在同一片段里换参考图。

部分模型（如 Flux 系）不写负面词，用正向描述规避。

## 验收

- [ ] 每个片段有档位、内容类型、图数
- [ ] 五张表逐项有依据（不是「感觉」）
- [ ] 一致性清单五项齐全
- [ ] 提示词包按模板填空，无中英混排
- [ ] 定妆照与场景图已先出并复用

## 分工

- 写脚本 → `video-shortform-script`
- 剪辑点判断 → `video-cut-grammar`
- 素材合成成片 → `video-compose`
- 本地出图/跑工作流 → `comfy-workflow`
