# 剪辑判断

## Rule of Six（优先级从高到低）

| 权重 | 判据 | 问题 |
|-----:|------|------|
| 51% | **情感** | 这一刻观众该有什么感觉？切了更强还是更弱？ |
| 23% | **故事** | 这一刀推进了信息/冲突/因果吗？ |
| 10% | **节奏** | 切点落在动作或音乐的呼吸上吗？ |
| 7% | **视线** | 观众的注意力在画面哪一侧？切完是否跳？ |
| 5% | **二维** | 构图轴线、左右关系是否连续？ |
| 4% | **三维** | 空间关系是否说得通？ |

**规则只有一条**：为了保住低权重项而牺牲高权重项，是错的。

- 节奏完美、情感断了 → 错；
- 故事讲通了、轴线跳了 → 可以接受；
- 三维穿帮、但情感更强 → 仍然可以接受（除非穿帮本身让人出戏）。

## 用法：每个切点问三句

1. 这一刀**为什么**在这里？（说不出就删掉这一刀）
2. 切之前观众在想什么？切之后想什么？
3. 如果不切，会损失什么？

三问答不上来 → 这个切点是「手痒」，合并掉。

## Cut sheet

```yaml
- id: 7
  from: "shot_03"
  to: "shot_04"
  at: 12.4            # 秒
  reason: emotion     # emotion / story / rhythm / eye / 2d / 3d
  note: "从犹豫切到决断，观众要在这口气上被推一下"
  sound: "鼓点落，BGM 抬 2dB"
```

字段要求：

- `reason` 必须是六项之一，不允许「感觉」；
- `sound` 可驱动配乐包络（与 `video-compose` 的 timeline 对接）；
- `at` 精确到帧，导出时换算。

## 诊断「剪完不对」

按顺序排除：

1. **情感断层**：相邻两镜的情绪强度差太大 → 加过渡镜头或改顺序；
2. **故事空转**：连续两刀都没推进信息 → 删一段；
3. **节奏打架**：切点与音乐重音错位 → 挪到最近的节拍；
4. **视线跳**：上一镜人物看右、下一镜看左 → 翻转画面或换镜头；
5. **轴线乱**：空间关系不成立 → 补一个交代镜头。

前三条占九成。

## 卡点剪辑的边界

- 卡点只服务节奏（10%），**不能为了踩点牺牲情感与故事**；
- 每个重音都切 → 观众疲劳；重音切 + 弱拍留白，才有呼吸；
- 快剪段落里允许 1–2 个「错拍」，刻意的不齐反而更有劲。

## 验收

- [ ] 每个切点都能说出 `reason`
- [ ] 没有连续两刀都不推进故事
- [ ] 情感曲线是递增或有意的起伏，不是平的
- [ ] 全部切点与音乐网格偏差 ≤ 100ms（刻意的除外）
- [ ] 关掉声音看一遍，仍然看得懂

## 分工

- 落地渲染 → `video-compose`
- 写脚本 → `video-shortform-script`
- 字幕 → `video-captions`
