# 提示词包模板

> 四块：定妆照 → 场景图 → 分镜图 → 视频。**按模板填空**，不临场自由发挥。
> 写法纪律：**英文优先、中英不混排**（生图/生视频模型对英文更稳）；描述里只写「看得见的东西」。

## 取料地图

| 字段 | 取自 |
|---|---|
| 镜头头（场次 / 内外景 / 日夜） | 剧本 |
| 景别 / 角度 / 运镜 / 光影 / 节奏 / 图数 | [decision-tables.md](decision-tables.md) |
| 角色外观 | 角色设定（年龄、体型、五官、发型、服装） |
| 情绪 | 微表情词（眉心、嘴角、眼神、呼吸） |
| 场景 | 场景设定图 + 材质/光源描述 |
| 一致性 | 定妆照 + 场景图 + 五项清单 |

## 模板 A · 定妆照（先出，全片锁脸源）

```text
A front-facing character portrait, head and shoulders, looking at viewer,
<年龄段/体型/脸型/发型发色/眼型>, <服装+配饰>, <标志性微表情>,
even frontal lighting, clean background, no occlusion
```

要点：正脸、无遮挡、均匀打光、干净背景。**只出一张，之后所有镜头复用。**

## 模板 B · 场景设定图（同场景的机位锚点）

```text
Wide establishing shot of <场景>, <时间/天气>, <材质与陈设>, <光源方向与色温>,
no characters, clean composition, <风格词>
```

要点：无人物、全景、全貌构图；同场景所有分镜共用这一张。

## 模板 C · 分镜图（关键帧）

```text
<景别>, <角度>, <运镜状态>, <角色+动作+表情>, <场景+道具>, <光影四要素>,
<风格词>, <画质词>
```

镜头头先写清：

```text
【场 3 / 内景 / 夜】中景 · 平视 · 固定 · 低调冷光
```

## 模板 D · 视频（首帧 + 运动 + 时长）

```text
[first frame: <分镜图描述>]
[motion: <主体动作> + <镜头运动，如 slow dolly in>]
[duration: <秒>] [aspect: <16:9 | 9:16>]
<风格词> <画质词>
```

要点：**首帧 = 对应分镜图**；运动只写一个主运动 + 一个次运动，写多了会打架。

## 一致性清单（每镜复核）

```text
- 身份：同一张定妆照贯穿
- 服装：颜色/款式/破损状态逐帧延续（第 3 镜袖口裂开，之后要延续）
- 道具：刀/伤痕/关键物件的位置与状态连续
- 位置：场景内相对位置与轴线不跳
- 首帧：视频首帧 = 对应分镜图
```

## 负面词（可选，按模型决定要不要写）

```text
deformed, bad anatomy, extra fingers, text, watermark, logo,
oversaturated, overexposed, blurry, lowres
```

- 支持独立负面词的模型：填进负面词参数；
- 不支持的（部分 Flux 系）：**不要写负面词**，改用正向描述规避（例如写 `clean background` 而不是 `no text`）。

## 常见返工原因

| 现象 | 原因 | 改法 |
|---|---|---|
| 换脸 | 中途换了参考图 | 回到同一张定妆照 |
| 场景跳 | 每个镜头各写场景 | 共用一张场景设定图 |
| 动作糊 | 一帧塞两个动作 | 拆成两镜 |
| 情绪不对 | 只写了表情词，没写光影 | 加光影四要素 |
| 中英混排 | 描述里夹中文 | 整段译成英文再填 |
