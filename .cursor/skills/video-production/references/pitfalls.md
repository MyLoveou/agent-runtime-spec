# 踩坑清单

> 都是实际撞过、花时间才定位的。按「现象 → 原因 → 对策」记，标注核对时间；**平台与版本细节会过期，遇到先复核再照做**。

## 一、采集

### 1. 平台状态字段语义反了（2026-11）

- 现象：整批条目「连载/完结」全标反，肉眼在 App 上看是连载，脚本标完结；
- 原因：字段 `creationStatus` 在部分平台 `1 = 连载中`、`0 = 已完结`，与直觉相反；
- 对策：接新平台先用 2–3 条人工核对；把映射写进适配层并加测试。

### 2. 搜索接口被风控（2026-10）

- 现象：搜索返回 307 跳到人机验证页，换 UA、带 cookie 都无效；首页偶尔 502/503；
- 原因：站点对「搜索」这一 AJAX 加验证，**详情页仍免验证**；
- 对策：按 ID 抓详情；或等站点恢复。不要在这上面死磕 cookie。

### 3. 标题会变，按标题匹配会丢

- 现象：同一本书下期再抓，标题已不同，匹配失败；
- 对策：存平台链接/ID，按 ID 抓；标题只作为初筛。

## 二、素材

### 4. 字幕烧在画面里（硬字幕）

- 现象：A 平台下载的画面上带字幕，B 平台同片没有；
- 原因：A 是硬字幕（只有 video+audio 两条流），B 有独立字幕轨；
- 对策：下载前先探测流结构；硬字幕按「换源 → 裁切 → 遮盖 → 修补」顺序处理。

### 5. 下载器拿不到高清（`n challenge solving failed`）

- 原因：新版下载器需要 JS 运行时解挑战；
- 对策：装对应 JS 运行时组件并显式指定（如 `--js-runtimes node`）；cookie 用浏览器登录态自动取，别手工导出。

### 6. 超分引擎在新显卡上崩

- 现象：跑到 90%+ 报 `0xC0000409`；CPU / 集显模式同样失败；
- 对策：换 waifu2x 系；先小批量验证再全量。

### 7. 封面出现白边

- 原因：统一画布时用了 contain + 透明填充；
- 对策：改 cover（`max` 缩放 + 居中裁切），验收看四角像素。

### 8. 去水印把字抹成色块

- 原因：水印压在文字/主体上；
- 对策：换源或裁切，不要硬修。自动检测不可靠，靠目视。

## 三、渲染

### 9. 封面入场「又动了一下」

- 现象：封面到位后轻微回弹；
- 原因：spring 缩放 `0.86 → 1` 过冲（约 1.02 再回落）；
- 对策：只淡入，`scale` 固定 1（见 [motion.md](motion.md)）。

### 10. 预览服务占用端口导致程序化渲染失败

- 原因：Studio 类预览占着固定端口，渲染时抓到的是预览页而不是合成；
- 对策：渲染前先停预览服务。

### 11. HMR 缓存旧模块

- 现象：长时间编辑后报 `ReferenceError: xxx is not defined`；
- 对策：大改后重启预览服务，别长时间挂着。

### 12. 尾部黑屏

- 原因：关掉片头后没有从总帧数里减掉片头时长；
- 对策：`opening ? OPENING_DURATION : 0`（见 [data-contract.md](data-contract.md) §4）。

## 四、环境与脚本

### 13. 中文路径读取失败

- 现象：图像库读中文路径返回空 / None；
- 对策：改用 PIL 读再转数组，或先复制到 ASCII 路径。

### 14. 大文件跨盘移动留下半搬状态

- 现象：跨盘 `move` 遇到只读文件报 `WinError 5`，源目录只剩一半；
- 原因：跨盘移动 = 复制 + 删除，只读文件删不掉；
- 对策：复制 → 校验文件数 → 递归清只读 → 删源。

### 15. 管道截断杀掉长任务

- 现象：下载/渲染中途被杀，留下 `.part`；
- 原因：`| Select-Object -First N` 之类会提前关闭管道；
- 对策：长任务重定向到日志文件或放后台，不要接截断管道。

### 16. 批量替换中文后文件变乱码

- 现象：替换后中文变成问号或乱码；
- 原因：脚本以非 UTF-8 编码读写，或写 JSON 时带了 BOM / 丢了 BOM；
- 对策：显式 UTF-8；写 JSON 时统一不带 BOM，读完先检查首字符；正则替换里 `$` 会被当变量，中文替换优先用脚本而不是命令行内联。

## 五、配音与字幕（2026-11 星铁那期）

### 17. 某一段音频像「电音 / 嗡嗡」

- 现象：只有某一段（书卡或结尾）发闷发嗡，其他段正常；换参考音频、调参数都没用；
- 原因：**同一段音频被播放了两遍**——分屏各自挂了 `<Audio>`，转场处两段同时发声，相位叠加就是梳状滤波；
- 对策：全片只留**一条合成音轨**（`full-voice.wav`），所有分屏的 `<Audio>` 统一加 `!options.fullVoice` 守卫；检查时逐个组件搜 `<Audio>`，别只修发现的那一处。
- 排查顺序：**先确认没有重复音频，再怀疑模型**。

### 18. 字幕和配音对不上

- 现象：个别书卡字幕整体偏早/偏晚，全片其他段正常；
- 原因：字幕时间是靠「静音检测猜句界」算的，但 TTS 在**逗号处也停 0.3–0.45s**，和句间插入的 0.30s 无法区分，句界经常挑错；
- 对策：生成配音时**逐句记录真实起止**（`句子时间.csv`），字幕直接读它，一个字节都不猜；
- 验收：统计「字幕区间内语音占比」，应有 0 条低于 35%，且「有声被字幕覆盖」≈100%。

### 19. 配音「一字一顿」

- 原因：分句时按逗号切，把「性压抑，」这种 3 字短句单独送进 TTS，句首句尾各自生成再拼接；
- 对策：**只按句号切**；单句 >90 字才在逗号处切，且把 <12 字的碎片并回上一句。

### 20. 句尾拖音

- 现象：每句结尾都拖一段长尾，句间又插 0.5s 停顿，整体很拖；
- 原因：模型对每句结尾都会拖尾，参考音频长短改变不了（实测 7.9s 参考 8.00s、8.6s 参考 8.20s）；
- 对策：逐句生成 → **每句裁掉首尾静音** → 按标点插固定停顿（逗号 0.18s / 句号 0.30s）。

### 21. 配音跟画面「错位」：念完了才翻图

- 现象：书卡念完才切到配图屏，图跟口播无关；
- 原因：配图屏被当成独立一屏排在书卡之后，时长又叠加在书卡之外；
- 对策：把这段配音按比例切开，书卡播前段、配图屏用 `startFrom` 接着播后段；配图屏的时长从这段配音里**扣**，不要额外加。

### 22. 卡片文字和配音念的不是一回事

- 现象：屏幕上是很长一段平台简介（还带换行、台词），配音念的却是改写后的短简介；
- 原因：卡片描述取自元数据 `synopsis`，不是口播稿；
- 对策：卡片文字**一律从口播稿取**（简介 + 评价），保证「看到的 = 听到的」。

## 六、视频素材裁剪（2026-11 星铁那期）

### 23. 裁掉片头却留下 logo

- 原因：只按「黑场 + 静止」判定，而片头常是**连续两三张** logo 卡，裁到第一张边界就停了；且 `-ss ... -c copy` 会吸附到上一个关键帧，头一刀根本没生效；
- 对策：判定加**亮度**（连续 2 秒黑占比<50% 且平均亮度>30 才算正片，logo 卡亮度只有 1–15）；裁剪先 `ffprobe -skip_frame nokey` 列关键帧，取「≥目标位置」的第一个关键帧再切，保证无损且切到位。

### 24. 拼接后时长翻倍 / 解码报错

- 现象：两个 3 分钟片段拼出 11 分钟，播放报参考帧丢失；
- 原因：`concat` demuxer 直接 `-c copy`，两段参数（时间基/帧率）不一致时时间戳错乱；
- 对策：用 `filter_complex` 的 `concat` 滤镜统一 `scale/fps/setsar` 后重编码；拼完跑一次 `ffmpeg -v error -i out -f null -` 验证解码无报错。

### 25. 裁水印留下亮块

- 原因：用「贴一条画面过去」补水印，色差不均，留下可见矩形；
- 对策：整幅**内缩 3~5% 再放大回去**，把角落连水印一起切掉；比修补干净。

## 七、版式与导出（2026-11 星铁那期）

### 26. 浅色遮罩把背景动画盖死

- 现象：加了背景视频后，为保可读性盖了一层白，结果背景几乎看不见；
- 对策：遮罩降到 30~45% 的**全幅渐变**（左重右轻），再给正文加**白色文字光晕**补对比度；不要用「一块实心面板」。

### 27. 封面 B 站尺寸切掉标题

- 原因：从 16:9 居中裁 1146×717，左下角标题被切一半；
- 对策：按**左下角锚定**裁切（标题在角上就锚那个角）。

### 28. 时长兜底常量跨期复用

- 现象：本期成片算出 24 分钟，实际 4 分钟；
- 原因：算每条时长时，遇到「下一屏 start 为 None」就回退到上一期写死的总长常量；
- 对策：兜底一律用**本期清单实测值**；`None` 要跳过继续找下一个真实起点。

### 29. 局部变量覆盖了累计变量

- 现象：重跑后总时长从 252s 变成 88s；
- 原因：函数里用同名变量当局部计数器，把外层累计起点覆盖了；
- 对策：局部计数器用独立命名（`local_t`），改完先跑一次看总量级对不对。

## 维护方式

新坑先进 `temp/` 的收件箱，**同类出现第二次再并入本文件**；并入时写清楚「适用版本 / 核对时间」。
