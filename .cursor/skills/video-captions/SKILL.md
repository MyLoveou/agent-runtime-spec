# 字幕

## 先选形态

| 形态 | 适用 | 代价 |
|------|------|------|
| **逐词高亮**（karaoke） | 竖屏短视频、口播、信息流 | 需要词级时间戳；样式要提前定死 |
| 整句切换 | 长视频、访谈 | 需要句级时间戳 |
| 只给平台字幕轨（外挂） | 用户能关字幕的平台 | 样式不可控，但可检索 |

短视频默认选逐词：观众静音刷，字幕就是主内容。

## 逐词字幕的四条硬规则

1. **布局冻结**：整句的字在屏幕上的位置从第一个词出现起就不变，后面只是逐个点亮——**禁止回流换行**；
2. **一句一行**：每行 ≤ 3 个词（中文 ≤ 8 字），超了就提前断句；
3. **当前词高亮**：其余词半透明或降饱和，只有当前词是主色；
4. **不遮挡主体**：字幕区落在安全区内（底部 15%–20%），不压脸、不压产品。

「布局冻结」是逐词字幕与普通字幕最大的差别：先算好整句的排版，再把每个词的显示时间点套上去。

## 时间轴

- 词级时间戳来自 ASR（强制对齐），不要手打；
- 每个词的最小停留 **80ms**，低于这个数观众读不到；
- 词与词之间留 **1–2 帧空隙**，避免粘成一坨；
- 句子切换时给 **2–3 帧**空白，形成呼吸。

对齐三条规则（与 `video-production` 的字幕章节一致）：

1. cue 用成片**绝对帧**，不用镜头内相对帧；
2. 有转场重叠时，第 N 段的起点要减 `重叠帧数 × (N−1)`；
3. 片头有固定时长时，正文 cue 从片头之后开始累加。

## 样式

| 项 | 建议 |
|---|---|
| 字号 | 按画面高度比例：竖屏 `height × 0.045` 左右 |
| 字重 | 粗体；细体在手机上看不清 |
| 描边 | 2–3 px 深色描边，或半透明底条 |
| 对比 | 白字 + 深描边，任何背景都成立 |
| 位置 | 底部安全区，水平居中 |
| 动效 | 只做透明度切换，不做弹跳/缩放 |

## 烧录 vs 外挂

- **烧录**（ASS/SRT 滤镜）：样式完全可控，平台转码后仍在；不可关闭、不可检索。
- **外挂**：可关闭、可检索，但样式随平台变。
- 短视频默认烧录；长视频两种都给。

烧录与统一帧率的命令见 `video-compose` 技能里的 FFmpeg 配方一节。

## 验收

- [ ] 逐词时，整句排版从头到尾不位移
- [ ] 每行词数符合上限
- [ ] 最短词停留 ≥ 80ms
- [ ] 无「字幕比声音早半句」的整体偏移
- [ ] 抽三点（开头/中段/结尾）与口播同句
- [ ] 手机竖屏全屏看一遍，无遮挡、无出界

## 常见错位

| 现象 | 原因 |
|---|---|
| 整体提前 | 忘了加片头时长 |
| 越往后越早 | 每段少减了转场重叠，误差累积 |
| 某段没字幕 | 该段起点识别错，回看 ASR |
| 字幕糊 | 烧录分辨率低，或字号按像素写死 |
