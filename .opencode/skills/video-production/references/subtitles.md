# 配音切片与字幕对齐

> 把一条整轨录音切成按条目分段的音频，并生成与画面时间轴严格对齐的字幕。

## 一、流程

```
整轨录音
 → 找每段起点（ASR 识别「第 N 个」这类序号词的时间戳）
 → 切成 N 段 + 开场 / 过渡 / 结尾
 → 写配音清单_实际.csv（真实起点、真实秒数）
 → 渲染按真实起点排时间轴
 → 字幕用同一套时间轴生成
```

人工听写切点太慢：一条 7 分钟的整轨，逐句听标要半小时以上；ASR 定位只要几分钟，再用人工抽查。

## 二、ASR 定位切点

- 用 `faster-whisper` 一类**本地可跑**的模型（`small` 级别即可，CPU 能跑）；
- 先 `ffmpeg` 转 16k 单声道 wav 再喂给模型（直接传原文件常报参数错误）；
- 在转写文本里找序号词（「第 N 个」「第 N 本」等），取该词的时间戳作为段起点；
- 只信时间戳，不信模型的分句 —— 分句用于定位，切点用于时间轴。

**坑**：整段转写若直接传文件路径，某些版本会因 metadata 参数报错；转成 wav 再传 numpy 数组可绕过。

## 三、切片与清单

- 切片用无损拷贝（`ffmpeg -ss … -to … -c copy`），快且不损音质；
- 命名 `item_01.wav … item_NN.wav`，另有 `opening_01`、`transition`、`ending`；
- 清单必须包含这些列：

```csv
id,title,text,chars,actual_start,actual_end,actual_seconds,suggested_seconds,estimated_seconds
item_01,条目名,正文,字数,19.25,41.42,22.17,20,22
```

- `actual_start`：**整轨里的绝对秒数**，渲染靠它排序；
- `actual_seconds`：这张卡显示多久；
- `estimated_seconds`：写稿时的估算，只用于草稿片，**不许进成片时间轴**。

## 四、字幕对齐三条规则

1. **cue 用绝对帧**（成片里的帧号），不是卡片内的相对帧；
2. **减掉转场重叠**：每两项重叠 8 帧，第 N 项实际起点要减 `8 × (N−1)`，否则越往后字幕越早；
3. **片头单独处理**：片头内 cue 可写死；正文 cue 从 `OPENING_DURATION` 之后开始累加。

## 五、错位排查

| 现象 | 原因 |
|------|------|
| 字幕整体提前 | 忘了加片头时长 |
| 越往后越早 | 每项少减 8 帧，误差累积 |
| 某段没字幕 | 该段起点识别错，回看 ASR 结果 |
| 音画不同步 | 时间轴用了估算秒数 |

排查顺序：先看第 1 张卡是否对齐 → 再看第 2 张 → 若第 1 对齐、后面越来越早，一定是转场重叠没减。

## 六、验收

1. 整轨时长与清单最后一条 `actual_end` 对齐（`ffprobe` 读 duration）；
2. 渲染后抽三点（开头 / 中段某条 / 结尾）确认字幕与口播同句；
3. 快进整片，确认没有「字幕比声音早半句」的滑移。

## 七、省事的替代

- 不追求逐句字幕：只做画面文字（条目名 + 关键信息），配音不下字幕；
- 想省对齐：ASR 转写后按句子重新切，不与卡片严格对齐；
- 纯音乐/无人声片：直接上 BGM，不需要这一环。

## 八、资产位置

```
<期目录>/素材/音频/
├─ 整轨.wav
└─ voice/ item_01.wav …
<期目录>/文案/配音/
├─ 配音清单.csv          # 录制前：分段文本 + 预估秒数
├─ 配音清单_实际.csv      # 录制后：真实起点 / 时长
└─ 配音文本_分段.txt
```
