# 分镜决策表

> 目标：把「剧本片段 → 视听参数」变成**确定性映射**——同样输入永远同样输出，可解释、可修正。

## 一、六个决策输入

| 输入 | 分析什么 |
|---|---|
| 内容类型 | 对白 / 动作 / 情绪 / 环境 / 悬念 / 揭示 |
| 信息焦点 | 这段要传达什么：环境 / 关系 / 动作 / 情绪 / 细节 |
| 情绪强度 | 平静 / 紧张 / 爆发 |
| 权力关系 | 谁强谁弱、威胁方向 |
| 空间关系 | 室内外、距离、大小 |
| 节奏倾向 | 快 / 慢 |

## 二、内容类型判别（六类，取主导）

> 铁律：**有动作 ≠ 动作**。看动作的**目的**，不看数量。

| 类型 | 判据 | 反例 |
|---|---|---|
| 对白 | 以台词推进；动作只是收束或过渡 | 打完收刀再放话 → 对白 |
| 动作 | 实体冲突为主，目的是分胜负 | 拔刀只为威慑 → 悬念 |
| 情绪 | 无对抗，角色静立/凝望，重在内心落点 | 黑影离去 + 收刀 → 情绪 |
| 环境 | 空镜或无主要角色动作，交代氛围 | 有人走但镜头在环境 → 环境 |
| 悬念 | 有动作但目的是蓄力/铺垫（搭刀柄、逼近、藏匿） | 拔刀未交手 → 悬念 |
| 揭示 | 关键信息揭露或反转（揭面、亮底牌） | 悬念的答案落地 → 揭示 |

## 三、五张决策表

### 表 1 · 景别（信息焦点 → 景别）

| 焦点 | 景别 |
|---|---|
| 环境 / 位置 | 远景 / 大远景 |
| 人物与环境 / 动作幅度 | 全景 |
| 双人关系 / 身体语言 / 对白 | 中景 |
| 情绪转折 / 关键反应 | 近景 / 特写 |
| 细节 / 眼神 / 手部 / 关键道具 | 大特写 |

### 表 2 · 角度（权力关系 → 角度）

| 权力 | 角度 | 效果 |
|---|---|---|
| 强势 / 威压 | 仰拍 | 放大压迫 |
| 弱势 / 被支配 | 俯拍 | 放大渺小 |
| 对等 / 客观 | 平视 | 中性 |
| 代入主观 | POV | 观众成为角色 |
| 世界失衡 / 不安 | 荷兰角 | 倾斜即失序 |

### 表 3 · 运镜（运动目的 → 运镜）

| 目的 | 运镜 | 效果 |
|---|---|---|
| 主体移动 / 追击 | 跟 / 移 | 主体保持画面重心 |
| 悬念揭晓 / 视线聚焦 | 推近 | 空间压缩 |
| 段落结束 / 离开 | 拉远 | 空间释放 |
| 建立场景关系 | 摇 | 揭示空间联系 |
| 不安 / 纪实 / 慌乱 | 手持 | 抖动即情绪 |
| 对峙 / 压抑 | 固定 | 静止即紧张 |

### 表 4 · 光影（情绪基调 → 四要素：光源 / 方向 / 质感 / 色温）

| 基调 | 光影 | 效果 |
|---|---|---|
| 压抑 / 危险 | 低调 + 冷色（侧上、硬光、蓝灰） | 阴影吞噬 |
| 希望 / 安全 | 高调 + 暖色（正面柔光、金黄） | 明亮温暖 |
| 神秘 / 悬念 | 硬侧光半明半暗（单侧、中性偏冷） | 藏一半露一半 |
| 悲怆 / 牺牲 | 逆光剪影（正后硬光、青灰） | 轮廓化 |
| 诡异（室内） | 顶光 / 底光（硬光、冷色） | 面部阴影变形 |
| 威胁 / 月夜 | 冷月光硬侧光（侧后、银蓝） | 月夜威胁标配 |

### 表 5 · 节奏（强度 × 信息密度 → 镜头时长与切法）

| 内容 | 节奏 |
|---|---|
| 对白 / 情绪戏 | 3–5 秒，少切，留气口 |
| 动作 / 追击 | 1–2 秒，快切，动作匹配 |
| 悬念 / 揭示 | 缓慢推近 + 停帧 |
| 环境 / 空镜 | 慢，长镜头留白 |
| 高潮爆发 | 快速剪辑 + 特写堆叠 |

## 四、仲裁（冲突时按此让步）

```
情绪基调 > 信息层级 > 权力关系
```

例：「强势反派表白」——权力想要仰拍，情绪想要特写 → **特写赢**。

## 五、档位与图数

### 选档

| 档位 | 信息点 | 例子 |
|:---:|---|---|
| 5s | 1 个 | 一个眼神、一次受击、空镜 |
| 10s | 2–3 个 | 起身→走到门边→回头；两三句台词 |
| 15s | 4+ 个 | 完整对话、情绪转折、小高潮 |

### 图数（档位 × 节奏）

| 档位 | 慢 | 中 | 快 |
|:---:|:---:|:---:|:---:|
| 5s | 1–2 | 2 | 3–6 |
| 10s | 2–4 | 3–5 | 5–10 |
| 15s | 4–8 | 5–8 | 10–20 |

### 每镜关键帧修正（按运镜复杂度）

| 镜头 | 关键帧 | 画哪些 |
|---|---|---|
| 固定机位 | 1 | 一张代表整镜 |
| 简单运镜（推/拉/摇） | 2 | 起幅 + 落幅 |
| 复杂运镜（环绕/跟拍） | 3 | 起幅 + 转折 + 落幅 |
| 动作镜头 | 2–3 | 起势 + 顶点 + 受击 |

### 换算成视频段数

按「每段 3–5 秒」估算，再按所用模型的分段上限调整（有的只支持 5 秒整数倍）：

```
5s 档  → 1 段  → 2 张控制图
10s 档 → 2–3 段 → 4–6 张
15s 档 → 3–5 段 → 6–10 张
```

## 六、输出

```yaml
- shot: 3
  duration: 3s
  content_type: 情绪
  focus: 情绪转折
  shot_size: 近景
  angle: 平视
  camera: 固定
  light: 低调 + 冷色
  frames: 1
  note: "听到名字后的一顿，留 0.5 秒气口"
```

这张表直接给 `video-compose` 的 EDL 或 `comfy-workflow` 的生成参数用。
